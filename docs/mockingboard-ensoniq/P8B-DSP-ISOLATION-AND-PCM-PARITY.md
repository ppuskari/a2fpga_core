# P8B — SSI-263 DSP stabilization and reference comparison

Branch: `petar/ssi263-p8b-dsp-validation-20261109`

Base: `petar/ssi263-fullchip-p8-reference-20261109`

**Status: source-level DSP tests pass; silicon/acoustic equivalence FAILS.
The firmware/hardware piano baseline remains protected. Do not enable
P8B speech in the HDMI mixer.**

## Motivation: verified hardware regression

On physical Enhanced Apple IIe hardware the experimental P8 chip produced
complete static, and the previously rich DOC piano became scratchy.

The user set `MB_SPEECH_GAIN_NUM = 0` and confirmed the piano immediately
returned to its correct sound. The problem was P8 speech contaminating
the shared HDMI mixer; no changes to DOC piano rendering are justified.

P8B enables the independent chip for synthesis but **hard mutes its HDMI
contribution**:

- `MOCKINGBOARD_SSI263_FULL_CHIP_ENABLE = 1'b1`
- `MB_SPEECH_GAIN_NUM = 0`

P6 DOC multisample piano, AY FX, oscillator allocation and music volume
code remain unchanged. No BL616 MCU update.

## Changes for steps 1–5

### 1. Signed arithmetic and signal scaling

- Signed 64-bit high-pass feedback intermediate, explicitly saturated to
  32-bit state before writing feedback registers. Prevents 32-bit wrap.
- Correct glottal VA and CTL amplitude normalization: divide by
  **15 × 15 = 225**, not the erroneous `>>> 12` (~4096).
  That error alone had silenced much of the voiced source.
- Chip output gain is an explicit standalone parameter
  `OUTPUT_GAIN_NUM=6` applied before 16-bit saturation, never applied
  to the shared music channel.

### 2. Audio output

- Upgraded PCM output clock from 16 kHz to **44.1 kHz**.
- Five-tap linear-phase FIR `[1,4,6,4,1]/16` over the sample-and-hold
  output to attenuate filter-clock alias images.
- This is a **first anti-image FIR**, not equivalent to the pinned C
  model's 48-tap/oversampled FIR, fractional area resampler, or complete
  physical SSI-263 output stage. This distinction is important: a
  nonzero waveform is not evidence of analog equivalence.

### 3. Excitation/noise isolation

- Independent `EXCITATION_VOICE_ENABLE` and
  `EXCITATION_NOISE_ENABLE` synthesis-time gates.
- Both off: exactly 0 PCM over the sample trace.
- Voice-only: nonzero without noise.
- Noise-only: nonzero during die-coded high-FA unvoiced phoneme $28.
- Replaced the arbitrary Q8 formant-control increment with the
  upstream frame-relative transition law using Q12, an 8-entry
  articulation table and 16-entry speech-rate reciprocal table.
  F1 has its upstream 2.25× field speed; VA/FA have 6× speed.
- Volume amplitude now glides over the actual phoneme duration in Q12
  instead of stepping a whole code every filter-clock sample.
- Modes 1/2 load pitch immediately, whereas mode 3 uses a Q12
  gliding target and the upstream R1 glide multipliers.
- Imported the **36-tick glottal kernel** from the pinned Pico reference,
  encoded as a new 64×16 signed ROM. This replaces P8's invented 15-tick
  approximation. ROM and provenance are regenerated by
  `tools/generate_ssi263_p8_roms.py --check`.
- P8 still requires the software model's calibrated noise shaper, F2/F5
  routing, closure/ramp rules, A/R lookahead and output reconstruction.

### 4. C/RTL objective comparison

`reference/ssi263/p8b_compare_trace.c` and
`tests/mb_ssi263/tb_ssi263_p8b_trace.sv`
use the same 1 MHz XCK setting and four successive 50 ms phoneme
windows: L ($20), A ($08), YI ($04), unvoiced noise ($28).
The C reference uses the exact MIT Pico SSI engine pinned in the tree.
Raw 50 kHz PCM16 sequences are compared by
`tools/compare_ssi263_p8b_audio.py`.

Measured GitHub Actions output at 2026-11-09:

| Metric | Pinned Pico C | P8B fixed-point RTL |
|---|---:|---:|
| Peak dBFS | 0.00 | -3.25 |
| RMS dBFS | -16.32 | -17.76 |
| Hard-clipped samples | 0.15% | 0.00% |
| Worst sample-to-sample step | 9279 | 6044 |
| Best lagged waveform correlation | reference | ~0.606 |

Correlation is not enough to approve the renderer. Band spectra also
differ substantially. A native SSI263 capture at
https://www.youtube.com/watch?v=Gciw3PYCVok
and `ssinativespeech.wav` remain the physical acoustic target; the
CI trace is only a **short model-vs-RTL gate**, not the native recording.

### 5. Music re-integration gating

**Not yet released.** Speech remains muted, and the CI asserts
`MB_SPEECH_GAIN_NUM=0` and unchanged DOC/AY music configuration.

An explicit minimum fidelity gate compares PCM correlation >=0.90,
RMS error <=2 dB, maximum six-band distribution difference <=7
percentage points, clipped fraction <=0.1%, and continuity.
This gate currently FAILS. Passing it will only authorize a
controlled, low-gain hardware experiment after Gowin resource/timing
checks and native-reference comparison. It is NOT proof of exact
silicon equivalence.
